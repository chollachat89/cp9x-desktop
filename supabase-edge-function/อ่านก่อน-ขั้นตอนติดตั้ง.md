# อัปเดตรอบนี้ (v1.0.57) — ขั้นตอนติดตั้ง

รอบนี้แก้ **ฝั่งเซิร์ฟเวอร์ + ฝั่งหน้าแอป + มี SQL ใหม่** ต้องรัน SQL → deploy → build ตามลำดับ

## นี่คือการเปลี่ยนแปลงอะไรบ้าง (v1.0.57)

### แยกสิทธิ์ "ผู้ตรวจสอบ" ออกจากแอดมิน — ตรวจ 2 ฝ่ายจริง

| ขั้น | ใครทำได้ | ทำอะไรได้ | ตัดบิลไหม |
|---|---|---|---|
| 1. อนุมัติ / ตีกลับ | **แอดมิน** | ตรวจเอกสารรอบแรก | ❌ ไม่ตัด |
| 2. สิ้นสุดงาน / ตีกลับ | **ผู้ตรวจสอบเท่านั้น** | ตรวจซ้ำแล้วปิดจ็อบ | ✅ ตัดตอนกด "สิ้นสุดงาน" |

**แอดมินทั่วไปกดขั้นที่ 2 ไม่ได้แล้ว** — จะเห็นแค่ข้อความ "รอผู้ตรวจสอบ · แอดมินกดขั้นนี้ไม่ได้" ถ้าพยายามยิงคำสั่งตรง ๆ เซิร์ฟเวอร์ก็ปฏิเสธอีกชั้น

**ผู้ตรวจสอบมีปุ่ม "ตีกลับ" ด้วย** — กันกรณีแอดมินอนุมัติมาแล้วแต่ตรวจซ้ำเจอว่ายังไม่เรียบร้อย · ตีกลับแล้ว**ไม่แตะบิลเลย** แค่ดึงสถานะกลับไปให้ผู้รับเหมาแก้ใหม่ · บังคับกรอกเหตุผลเสมอ ผู้รับเหมาจะเห็นข้อความนั้น

**ประวัติแสดงครบทั้ง 2 ฝ่าย** ในคอลัมน์หมายเหตุของทุกแถว:

```
อนุมัติโดย ฮานีฟ • 08/09/2026 14:30
สิ้นสุดงานโดย Phutphum • 08/09/2026 16:05
```

ถ้าผู้ตรวจสอบตีกลับ บรรทัดที่สองจะเป็น `ตีกลับโดย ...` แทน และ**ชื่อผู้อนุมัติเดิมยังอยู่ไม่ถูกลบ** จะได้ตามได้ว่าใครอนุมัติผ่านมาก่อนหน้า

### ผู้ตรวจสอบ 3 บัญชี

`Superbaipo` · `Admin` · `Phutphum`

ทั้ง 3 คน**ยังเห็นทุกเมนูเหมือนแอดมินเดิมทุกอย่าง** ไม่ได้ถูกลดสิทธิ์อะไรเลย — แค่ได้สิทธิ์ขั้นที่ 2 เพิ่มเข้ามา

> **ทำไมใช้ธง `is_checker` ไม่เปลี่ยน `role` เป็น `'checker'`**
> เพราะบัญชี `Admin` อยู่ในรายชื่อผู้ตรวจสอบด้วย ถ้าเปลี่ยน role บัญชีนั้นจะหลุดสิทธิ์แอดมินทั้งหมดทันที — เปิดงาน ปิดงาน วางบิล ใช้ไม่ได้เลยสักอย่าง

## ขั้นตอนติดตั้ง (3 ขั้น ตามลำดับนี้เท่านั้น)

**ขั้นที่ 1 — รัน SQL**

เปิด `add-สิทธิ์ผู้ตรวจสอบ.sql` → วางทั้งไฟล์ → **Run** ที่
https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/sql/new

⚠ **ต้องทำก่อน deploy เสมอ** เพราะโค้ดใหม่อ่านคอลัมน์ `is_checker` ถ้ายังไม่มีคอลัมน์จะ**เข้าสู่ระบบไม่ได้ทั้งระบบ**

ดูผลตรวจท้ายไฟล์ให้ครบ **3 บัญชีขึ้น ✅ ตั้งธงแล้ว** ถ้าขึ้น ❌ ไม่พบบัญชี แปลว่าชื่อผู้ใช้จริงสะกดไม่ตรง — ในไฟล์มีคำสั่งแก้ให้พร้อม

**ขั้นที่ 2 — Deploy Edge Function**

https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/functions/app-api → **Edit function** → คัดลอก `index.ts` วางแทนทั้งไฟล์ → **Deploy**

**ขั้นที่ 3 — Build แอป**

Build แอปใหม่ แล้ว push tag `v1.0.57`

**วิธีเช็คว่าได้ผลจริง:**

1. ล็อกอินด้วยแอดมินที่**ไม่ใช่** 3 คนนี้ → แท็บ "ไฟล์ผู้รับเหมาส่งกลับ" ต้อง**ไม่มีปุ่มสิ้นสุดงาน** เห็นแค่ "รอผู้ตรวจสอบ"
2. ล็อกอินด้วย `Phutphum` → ต้องเห็นปุ่ม **สิ้นสุดงาน** และ **ตีกลับ**
3. กดสิ้นสุดงาน → บิลหายจากตารางผู้รับเหมา และคอลัมน์หมายเหตุขึ้นชื่อครบทั้ง 2 บรรทัด
