# อัปเดตรอบนี้ (v1.0.55) — ขั้นตอนติดตั้ง

รอบนี้แก้ **ฝั่งเซิร์ฟเวอร์ + มีตารางใหม่ใน Supabase** ต้องรัน SQL + นำเข้า CSV + deploy Edge Function + build แอปใหม่

> ⚠ รอบนี้มีขั้นตอนมากกว่าปกติ เพราะเพิ่มการเก็บข้อมูลรับประกันเข้าระบบ ทำครั้งเดียวจบ รอบหน้าไม่ต้องทำอีก

## นี่คือการเปลี่ยนแปลงอะไรบ้าง (v1.0.55) — 3 เรื่อง

### 1. เปลี่ยนฟอร์มที่ผู้รับเหมาดาวน์โหลดเป็น "ฟอร์มแนบรูป" แบบใหม่

ใบงานเดิมมีกล่องรูปแค่ 5 คู่ (10 กล่อง) และหัวฟอร์มมีแค่ 5 ช่อง ตอนนี้เปลี่ยนเป็นฟอร์มแนบรูปตามแบบที่ใช้ส่งงานจริง

**กล่องรูป 10 คู่ (20 กล่อง)** เรียงตามลำดับการทำงานจริง:

| คู่ | ฝั่งซ้าย | ฝั่งขวา |
|---|---|---|
| 1 | รูปชื่อสาขา | รูปเลข Asset (ถ่ายให้อ่านตัวเลขได้ชัดเจน) |
| 2 | รูปอุณหภูมิก่อนซ่อม | รูปอุณหภูมิหลังซ่อม |
| 3 | รูปอะไหล่เก่าก่อนถอด | รูปอะไหล่ใหม่หลังเปลี่ยน |
| 4 | รูปการตรวจเช็คก่อนเปลี่ยน | รูปการตรวจเช็คหลังเปลี่ยน |
| 5 | รูปเทียบอะไหล่เก่าและใหม่ | รูปขณะปฏิบัติงานที่เกี่ยวข้อง |
| 6-10 | รูปขณะปฏิบัติงานที่เกี่ยวข้อง | รูปขณะปฏิบัติงานที่เกี่ยวข้อง |

**หัวกระดาษทำตามไฟล์ต้นฉบับทุกช่อง** — ผัง merge, ป้ายหัวข้อ, ความกว้างคอลัมน์, ความสูงแถว, **ขนาดตัวอักษร (10 และ 8), ไม่มีตัวหนา, ไม่มีพื้นสี** ตรงกับไฟล์ที่ส่งมาเป๊ะ

ข้อความ**ซ้อนขึ้นบรรทัดใหม่ได้เฉพาะช่องที่ต้นฉบับเปิดไว้** คือ ประเภทงาน · รายละเอียดทรัพย์สิน · ป้าย Warranty ทั้งสอง · วันเริ่มประกัน · ช่องที่เหลือ (ชื่อสาขา เลขที่งาน เลขทรัพย์สิน) บังคับบรรทัดเดียวแล้วให้ Excel ย่อตัวอักษรเองถ้ายาวเกิน

- แถว 1 — ชื่อสาขา (รหัส-ชื่อ) · ประเภทงาน · เลขที่งาน
  - **แก้รหัสสาขาซ้ำสองรอบ** — ชื่อสาขาที่เก็บในระบบมีรหัสนำหน้าอยู่แล้ว (`0464-บางเสร่`) พอเอารหัสมาต่อหน้าอีกเลยได้ `0464-0464-บางเสร่` · ตอนนี้เช็คก่อนว่าชื่อขึ้นต้นด้วยรหัสนั้นแล้วหรือยัง ได้ `0464-บางเสร่` ตามที่ควรเป็น
- แถว 2-3 — **1 แผ่นรองรับ 2 เลขทรัพย์สิน** ตามต้นฉบับ แต่ละบรรทัดมี เลขทรัพย์สิน · รายละเอียด · Warranty Start Date · Warranty Expire Date

ทุกช่องระบบเติมให้เองหมด · เลขงานที่มีทรัพย์สินตัวเดียว แถว 3 เว้นเป็น `-` ไว้ให้กรอกมือได้ · เลขงานที่มี 3-4 ทรัพย์สินจะได้ 2 แผ่น (แผ่นละ 2 ตัว) ชื่อแท็บบอกเลขที่อยู่ในแผ่นนั้น เช่น `130000003633+130000003875`

ช่องรับประกันเดิมต้องเปิดไฟล์ Excel ทะเบียนทรัพย์สิน 61,000 แถวมานั่งค้นเอง ตอนนี้ระบบเติมให้ในฟอร์มเลย

**เรื่องหน้ากระดาษ:** ทั้งฟอร์มอยู่ใน **หน้า 1 แผ่นเดียวจบ** (A4 แนวตั้ง) — ฟอร์มสูงราว 1,480pt แต่พื้นที่พิมพ์ A4 สูงราว 805pt Excel จึงย่อให้อัตโนมัติเหลือราว 54%

การย่อมีผลเฉพาะตอนพิมพ์และตอนดูพรีวิว **ตอนเปิดทำงานใน Excel กล่องรูปยังสูงเท่าเดิม** ผู้รับเหมาแปะรูปได้สบายเหมือนเดิม ไม่ต้องสู้กับกล่องจิ๋ว · เปิดไฟล์มาอยู่ในมุมมองแบ่งหน้าให้เห็นว่าเป็นหน้าเดียวจริง

ส่วนที่ **ไม่เปลี่ยน:** งานเคลมประกัน 3 เดือนยังไม่ออกฟอร์มเหมือนเดิม · ชื่อไฟล์ยังเป็น `ฟอร์มวางบิล_<เลขงาน>.xlsx`

### 2. เก็บข้อมูลรับประกันทรัพย์สินเข้าระบบ (ตารางใหม่ `asset_warranty`)

ดึงจากไฟล์ `ฟอล์มส่งรูปวางบิล.xlsx` ชีต `_Asset` ได้ **54,866 เลขทรัพย์สิน** ที่มีวันรับประกัน (จากทั้งหมด 61,464 แถว ที่เหลือช่องว่างเปล่า ฟอร์มจะขึ้น `-` ให้กรอกมือ)

- เก็บแยกเป็นตารางของตัวเอง ไม่รวมกับ `branch_assets` เพราะตารางนั้นมี 1,210 เลขที่ตั้งใจให้ซ้ำได้ (คนละคำอธิบายในสาขาเดียวกัน) ถ้ารวมกันข้อมูลรับประกันจะซ้ำตาม
- มี 166 เลขที่ปรากฏซ้ำโดยวันรับประกันไม่ตรงกัน เลือกเก็บ **แถวที่วันหมดประกันช้าที่สุด** เพราะทรัพย์สินอาจถูกต่อประกันหรือเปลี่ยนสัญญา ข้อมูลใหม่กว่าคือตัวที่ใช้จริงตอนเคลม
- ถ้ายังไม่ได้สร้างตารางนี้ ฟอร์มจะขึ้น `-` ในช่องรับประกัน **แต่ยังออกไฟล์ได้ปกติ** ไม่พังทั้งใบ

### 3. ล้างประวัติฟอร์มที่ผู้รับเหมาส่งกลับ (เริ่มนับหนึ่งใหม่ด้วยฟอร์มใหม่)

ไฟล์ `ลบประวัติฟอร์มที่ผู้รับเหมาส่งกลับ.sql` — ลบรายการที่ผู้รับเหมาส่งกลับทั้งหมด เพื่อให้ทุกคนโหลดฟอร์มใหม่ กรอกใหม่ ส่งใหม่

⚠ **สำคัญ: ลบประวัติอย่างเดียวไม่พอ** เพราะตอนแอดมินกดอนุมัติ ระบบจะปิดบิลของเลขงานนั้นไปด้วย งานที่ปิดบิลแล้วจะหายจากตารางฝั่งผู้รับเหมา เขาจึงไม่เห็นงานให้ส่งใหม่ · ไฟล์ SQL จึงมี **บล็อก D** ไว้เปิดบิลที่ถูกปิดจากการอนุมัติกลับมาให้ด้วย (แก้แค่ช่อง `completed_at` ไม่แตะข้อมูลอะไหล่/ราคา/รอบบิล)

ในไฟล์มีบล็อกอ่านอย่างเดียว A และ B ให้ดูก่อน และดาวน์โหลด CSV เก็บสำเนาไว้ได้ก่อนลบ

## ขั้นตอนติดตั้ง v1.0.55 (5 ขั้น)

**ขั้นที่ 1 — สร้างตารางข้อมูลรับประกัน**

เข้า https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/sql/new → เปิดไฟล์ `create-asset-warranty-table.sql` → คัดลอกเฉพาะ **ขั้นที่ 1** ในไฟล์ (บล็อก `create table`) → วาง → Run

**ขั้นที่ 2 — นำเข้าข้อมูลรับประกัน 54,866 แถว**

1. เข้า https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/editor
2. เลือกตาราง `asset_warranty` ทางแถบซ้าย
3. กด **Insert** → **Import data from CSV**
4. เลือกไฟล์ `asset-warranty.csv` (อยู่โฟลเดอร์เดียวกัน)
5. ตรวจว่าชื่อคอลัมน์จับคู่ครบทั้ง 4 ช่อง แล้วกด Import (ไฟล์ 2 MB ใช้เวลาราว 1-2 นาที)
6. กลับไปหน้า SQL รัน **ขั้นที่ 3** ในไฟล์ SQL เพื่อตรวจว่าได้ 54,866 แถวจริง

**ขั้นที่ 3 — Deploy Edge Function**

เข้า https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/functions/app-api → **Edit function** → คัดลอก `index.ts` วางแทนทั้งไฟล์ → **Deploy**

**ขั้นที่ 4 — Build แอป**

Build แอปใหม่ แล้ว push tag `v1.0.55`

**ขั้นที่ 5 — ล้างประวัติฟอร์มเก่า (ทำหลัง deploy เสร็จแล้วเท่านั้น)**

เปิดไฟล์ `ลบประวัติฟอร์มที่ผู้รับเหมาส่งกลับ.sql` → รันบล็อก A และ B ดูก่อน (เก็บ CSV ถ้าต้องการ) → แล้วรันบล็อก C และ D → จบด้วยบล็อก E เพื่อตรวจ

จากนั้นแจ้งผู้รับเหมาว่า **"เข้าแท็บฟอร์มวางบิล กดโหลด/รีเฟรช แล้วดาวน์โหลดฟอร์มใหม่ กรอกและส่งกลับอีกครั้ง"**

**วิธีเช็คว่าได้ผลจริง:** ล็อกอินเป็นผู้รับเหมา เข้าแท็บ "ฟอร์มวางบิล" กดดาวน์โหลดฟอร์มของงานที่มีเลขทรัพย์สินจริง → เปิดไฟล์ต้องเห็นกล่องรูป 20 กล่อง และหัวกระดาษแถวที่ 2 ต้องมีวันรับประกันเป็นตัวเลข ไม่ใช่ `-` · ถ้างานนั้นมี 2 เลขทรัพย์สิน ต้องเห็นทั้งคู่อยู่ในแผ่นเดียวกัน
