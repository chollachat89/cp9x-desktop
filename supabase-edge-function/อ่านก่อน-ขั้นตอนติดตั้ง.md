# อัปเดตรอบนี้ (v1.0.54) — ขั้นตอนติดตั้ง

รอบนี้แก้ **ฝั่งเซิร์ฟเวอร์ + ฝั่งหน้าแอป** — ไม่มี SQL ใหม่ ต้อง deploy Edge Function + build แอปใหม่

## นี่คือการเปลี่ยนแปลงอะไรบ้าง (v1.0.54) — 2 เรื่อง

### 1. จัดตำแหน่งปุ่มหน้าตารางวางบิลใหม่ ไม่ให้กระจุกกันเป็นแถวเดียว

เดิมกล่องทั้ง 6 กล่องเบียดกันอยู่ในแถวเดียว โดยเฉพาะกล่อง Excel ที่มีทั้งช่องเลือกรอบและติ๊ก 3 ประเภท ทำให้กล่องอื่นถูกบีบจนแคบ ส่วนพื้นที่ว่างด้านขวาไม่ได้ใช้เลย

ตอนนี้แบ่งเป็น **3 แถวตามหน้าที่**:

| แถว | มีอะไร |
|---|---|
| แถวบน | **ซ้าย:** โหลด/รีเฟรช · ประวัติรอบบิล — **ขวาสุด:** ล้างหน้าจอ · จัดการคอลัมน์ |
| แถวกลาง | 3 กล่องเอกสาร กว้างเท่ากันหมด: **เก็บเงิน CJ** · **เก็บเงินผู้รับเหมา** · **เคลมประกัน 3 เดือน** |
| แถวล่าง | **Excel รวม** เต็มความกว้าง มีที่หายใจพอสำหรับตัวเลือกทั้งหมด |

- แถวบนดันปุ่มมุมมองตารางไปชิดขวา ใช้พื้นที่ว่างที่เคยเหลือทิ้ง
- 3 กล่องเอกสารใช้ระบบคอลัมน์ กว้างเท่ากันเสมอ ไม่มีกล่องไหนถูกบีบให้แคบกว่าเพื่อน จอแคบก็เรียงลงมาเป็นแถวสวย ๆ
- ปุ่มดาวน์โหลด Excel ย้ายไปมุมขวาบนของกล่อง เห็นชัดว่ากดตรงไหนหลังเลือกเสร็จ

### 2. ติ๊กเลือกรอบบิลที่จะโหลดได้ทีละหลายรอบ

เดิมช่องเลือกรอบบิลของ Excel เป็น dropdown เลือกได้ **รอบเดียว** อยากได้ 3 รอบต้องโหลด 3 ไฟล์แล้วมารวมเอง

ตอนนี้เป็น **dropdown ที่ติ๊กได้หลายรอบ** กดที่ช่องแล้วรายชื่อรอบจะกางลงมา ติ๊กพร้อมกันกี่รอบก็ได้ แล้วได้ไฟล์เดียวจบ

- หัว dropdown สรุปให้เห็นเลยว่าเลือกอะไรไว้ — `ทุกรอบบิล` / `รอบที่ 63, 60, 59` / `เลือกไว้ 5 รอบ` (เกิน 3 รอบบอกเป็นจำนวน)
- ติ๊กหลายรอบรวดเดียวได้ พาเนลไม่ปิดหนีตอนติ๊ก · คลิกที่อื่นนอกพาเนลถึงจะปิด
- ในพาเนลมีปุ่ม **เลือกทุกรอบ** และ **ล้างที่เลือก** ไว้ให้กดรวดเดียว
- ไม่ได้ใช้ `select multiple` เพราะแบบนั้นต้องกด Ctrl ค้างถึงจะเลือกหลายอันได้ ผู้ใช้พลาดง่าย
- **ไม่ติ๊กรอบไหนเลย = เอาทุกรอบ** (เหมือนพฤติกรรมเดิม) ไม่ต้องไล่ติ๊กทีละรอบตอนอยากได้ทั้งหมด
- เอาเมาส์ชี้ที่รอบไหนจะเห็นช่วงวันที่ของรอบนั้น
- กด "โหลด/รีเฟรช" แล้วรอบที่ติ๊กค้างไว้ยังอยู่เหมือนเดิม ไม่ต้องติ๊กใหม่
- ชื่อไฟล์บอกรอบที่เลือกให้ครบ เช่น `ตารางวางบิล_รอบ61+62+63_ทุกประเภท_2026-09-05.xlsx`
- รอบเรียงตามตัวเลขจริง (2, 9, 10) ไม่ใช่เรียงแบบข้อความ (10, 2, 9)

ส่วนติ๊กเลือก **ประเภทการเก็บเงิน** 3 อย่างยังทำงานเหมือนเดิมทุกประการ
