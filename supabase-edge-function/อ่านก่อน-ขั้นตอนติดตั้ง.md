## v1.0.59 — ช่องค้นหาในตารางวางบิล

เพิ่มช่องค้นหาไว้ใต้ตัวกรองรอบบิล ใช้ตอนต้องการแก้อะไหล่ของเลขงานใดเลขงานหนึ่งโดยไม่ต้องเลื่อนหาทีละแถว

**ค้นได้ 5 อย่างพร้อมกัน** พิมพ์อะไรก็ได้ที่จำได้ — เลขงาน · เลขทรัพย์สิน · รหัสอะไหล่ · รายละเอียดอะไหล่ · ชื่อสาขา

**จุดที่ตั้งใจออกแบบไว้:**

- **กรองทันทีไม่ต้องรอโหลด** — กรองจากข้อมูลที่โหลดมาแล้ว ไม่ยิงไปเซิร์ฟเวอร์ ต่างจากตัวกรองผู้รับเหมา/รอบบิลข้างบนที่ต้องโหลดใหม่
- **⚠ ไม่มีผลกับปุ่มดาวน์โหลด** — ตั้งใจให้เป็นแบบนี้ เพราะถ้าให้มีผลด้วย พอลืมล้างช่องค้นหาแล้วกด CSV จะได้บิลไม่ครบแถวส่งให้ CJ = **เก็บเงินขาดโดยไม่รู้ตัว** ซึ่งแก้ย้อนหลังยาก · ตอนกำลังกรองจะมีป้ายสีเหลืองเตือนไว้ตลอดว่า "ปุ่มดาวน์โหลดยังออกครบทุกแถวตามปกติ"
- **เลขลำดับไม่เปลี่ยน** — แถวที่กรองออกมายังใช้เลขลำดับเดิมของตารางเต็ม ไม่ถูกนับใหม่เป็น 1, 2, 3 จึงอ้างอิงกับของจริงได้ตรง
- **ป้ายบอกจำนวน** — "แสดง 3 จาก 128 แถว" หรือ "ไม่พบ ... ในตาราง" จะได้รู้ว่าพิมพ์ผิดหรือไม่มีจริง
- **คำค้นไม่หายตอนกดรีเฟรช** — ยังกรองอยู่เหมือนเดิม ไม่เด้งกลับมาแสดงทุกแถว
- **กด "ล้างหน้าจอ" จะล้างคำค้นให้ด้วย** — กันกรณีโหลดชุดใหม่มาแล้วโดนคำค้นเก่ากรองทิ้งจนตารางว่าง แล้วนึกว่าโหลดไม่ติด

## v1.0.58 — เพิ่มประเภทการเก็บเงินแบบที่ 4: "ใบเสนอราคา"

| ประเภท | เก็บ CJ | เก็บผู้รับเหมา | สีในตาราง |
|---|---|---|---|
| เก็บเงินปกติ | ✅ | ✅ | ขาว |
| เคลมประกัน 3 เดือน | ❌ | ❌ | เหลือง |
| เคลมอะไหล่ | ❌ | ✅ | ฟ้า |
| **ใบเสนอราคา** ← ใหม่ | **✅** | **❌** | **ส้ม** |

"ใบเสนอราคา" เป็น**ภาพกลับด้านของ "เคลมอะไหล่" พอดี**

**ฝั่ง CJ — ขึ้นทุกอย่างตามปกติ:** เอกสารเก็บเงิน CJ (CSV/PDF) · ยอดเงินฝั่ง CJ ในประวัติรอบบิล · ใบเขียวฝั่งแอดมิน

**ฝั่งผู้รับเหมา — หายไปทั้งหมด:** ไม่ขึ้นในตารางวางบิล · ไม่ขึ้นในเอกสารเก็บเงิน · ไม่นับรวมในยอดเงิน · **ไม่ต้องส่งฟอร์มแนบรูปกลับ** (งานจะไม่โผล่ในแท็บ "ฟอร์มวางบิล" ของผู้รับเหมาเลย เหมือนเคลมประกัน 3 เดือน)

**ที่เห็นในแอป:** หน้าต่างเพิ่มอะไหล่มีตัวเลือกที่ 4 พร้อมคำอธิบายใต้ช่อง · ช่องประเภทในตารางเป็นสีส้ม · ปุ่ม Excel รวมมีช่องติ๊กเพิ่มเป็นช่องที่ 4 · ไฟล์ Excel แถวพื้นสีส้มและชีตสรุปมีบรรทัดของประเภทนี้

### บั๊กเก่าที่เจอระหว่างทำ และแก้ไปด้วย

หน้า **ประวัติรอบบิล** โค้ดเดิมบวกยอดฝั่งผู้รับเหมา**ทุกแถวโดยไม่ดูประเภทเลย** (ต่างจากฝั่ง CJ ที่เช็คถูกอยู่แล้ว)

ที่ผ่านมาไม่มีใครเห็นปัญหา เพราะประเภทเดิมที่ไม่เก็บเงินผู้รับเหมามีแค่ "เคลมประกัน 3 เดือน" ซึ่งถูกข้ามตั้งแต่ต้นอยู่แล้ว แต่พอมี "ใบเสนอราคา" เข้ามา **ยอดฝั่งผู้รับเหมาจะเกินความจริงทันที** — แก้ให้เช็คประเภทสมมาตรกับฝั่ง CJ แล้ว

## ขั้นตอนติดตั้ง (3 ขั้น ตามลำดับนี้เท่านั้น)

**ขั้นที่ 1 — รัน SQL**

เปิด `add-billing-type-ใบเสนอราคา.sql` → วางทั้งไฟล์ → **Run** ที่
https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/sql/new

⚠ **ต้องทำก่อน deploy เสมอ** — ฐานข้อมูลมีเงื่อนไข CHECK ล็อกไว้แค่ 3 ค่าเดิม ถ้า deploy ก่อนแล้วมีคนเลือก "ใบเสนอราคา" ฐานข้อมูลจะปฏิเสธ แอปขึ้น error ตอนกดบันทึกแถว

ไฟล์นี้**ไม่แตะข้อมูลเดิมเลย** แถวเก่าทุกแถวยังเป็นประเภทเดิม

**ขั้นที่ 2 — Deploy Edge Function**

https://supabase.com/dashboard/project/hefnjozijflnhdunmewl/functions/app-api → **Edit function** → คัดลอก `index.ts` วางแทนทั้งไฟล์ → **Deploy**

**ขั้นที่ 3 — Build แอป**

Build แอปใหม่ แล้ว push tag `v1.0.59`

**วิธีเช็คว่าได้ผลจริง:**

1. เข้าตารางวางบิล → ต้องเห็น**ช่องค้นหา**ใต้ตัวกรองรอบบิล → พิมพ์เลขงานหนึ่ง ตารางต้องเหลือเฉพาะแถวนั้น พร้อมป้ายเหลืองบอกจำนวน
2. ระหว่างที่ยังกรองอยู่ กด **CSV (CJ)** → ไฟล์ต้องออก**ครบทุกแถว** ไม่ใช่แค่แถวที่กรอง
3. กด + เพิ่มอะไหล่ → ต้องเห็นตัวเลือก **"ใบเสนอราคา"** เป็นอันที่ 4 · ตั้งแถวเป็นใบเสนอราคาแล้วช่องต้องเป็นสีส้ม บันทึกผ่านไม่ error
4. กด **CSV (CJ)** ต้องมีแถวใบเสนอราคา · กด **CSV (ผู้รับเหมา)** ต้องไม่มี
5. ล็อกอินเป็นผู้รับเหมา → งานที่เป็นใบเสนอราคาล้วนต้องไม่โผล่ในแท็บ "ฟอร์มวางบิล"
